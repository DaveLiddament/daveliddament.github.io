Rector Beyond Upgrades: Transforming Your Workflow

rector static analysis conference talk

Abstract

Rector is best known for code upgrades and refactoring, but it extends much further.

This talk explores how to use Rector to automate repetitive tasks, enforce coding standards, and ensure project consistency. We'll look at creating custom Rector rules tailored to specific project needs, with actionable steps to integrate Rector into development workflows.
