AI Writes Code. PHPStan Keeps It Honest.

static analysis phpstan ai symfony conference talk

Abstract

If AI can generate code quickly, how do we make sure that code actually meets our standards?

Whether code is written by humans, AI, or a mix of both, maintaining a clean, safe, and consistent codebase remains essential.

In this talk, I'll demonstrate how to create a custom PHPStan rule to enforce the coding standards used in my Symfony projects. A practical session for developers who want to combine AI-powered productivity with strong engineering practices.
