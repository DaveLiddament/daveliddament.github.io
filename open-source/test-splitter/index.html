Test Splitter

Test Splitter splits a PHPUnit test suite into deterministic batches, so the batches can be run in parallel CI jobs to cut build times.

DaveLiddament/test-splitter View on GitHub

Test Splitter takes the list of tests in a PHPUnit test suite and splits it into batches, in a deterministic way, so each batch can be run in a separate CI job. If your test suite takes 20 minutes to run, splitting it over 4 parallel jobs gets feedback to the team in roughly 5 minutes. Because the split is deterministic, the batches never overlap or miss a test.
