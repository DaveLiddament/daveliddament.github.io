SARB

SARB (Static Analysis Results Baseliner) makes it practical to introduce tools like PHPStan and Psalm to a large or legacy PHP codebase. Instead of fixing thousands of pre-existing issues up front, SARB baselines them so your build only fails on new issues — and, unlike other baselining approaches, it still tracks a baselined issue when its file is renamed or moved.
